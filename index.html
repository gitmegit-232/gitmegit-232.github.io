思考题

Q1：网页能否引用本地绝对路径图片（如 d:/images/1.png）？为什么？

不能。浏览器运行在安全沙箱中，禁止网页直接访问用户本地文件系统。 <img src="d:/images/1.png"> 这种写法浏览器无法加载， 因为 file:// 协议和 http:// 协议跨域，且存在安全风险。 正确做法是将图片托管到服务器上，通过 URL 或相对路径引用。

Q2：github.io 是静态托管，如何为博客添加评论功能？

可以通过嵌入第三方评论插件实现，无需自建后端：

  • utterances — 基于 GitHub Issues，评论数据存储在仓库 Issues 中，开源免费
  • Gitalk — 同样基于 GitHub Issues，中文社区使用广泛
  • Disqus — 老牌评论服务，免费但有广告
